# ANAY — Groupe musical

Static website for ANAY (Arrac n At Yanni).

## Publish with GitHub Pages

1. Create a new **public** GitHub repository.
2. Upload **all files and folders inside this package** to the repository root.
3. Make sure `index.html` is directly in the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)`, then click **Save**.
7. GitHub will publish the site at your GitHub Pages address.

## Edit the website

- Main page: `index.html`
- About page: `about.html`
- Gallery: `gallery.html`
- Styles: `css/styles.css`
- Interactions: `js/main.js`
- Images/logo: `assets/`

The booking form uses the email address configured in `js/main.js`.
Social-media links can be edited in `index.html`.

## Important

This is a static website. No paid hosting is required for GitHub Pages.
